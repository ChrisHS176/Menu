Ejercicio 01 • Retorno de Valores

Funciones que devuelven resultados

Este programa utiliza la función calcularAreaCirculo(radio) para calcular el área geométrica mediante Math.PI y redondear el resultado a dos decimales con .toFixed(2).

Simulador Interactivo

Salida del programa:

<html>
<body>
<font face="Arial">
<h2>Funciones que devuelven resultados</h2>

<script type="text/javascript">

function calcularAreaCirculo(radio) {
  var area = Math.PI * radio * radio; //calcula el área del círculo
  var area2 = area.toFixed(2); // lo ajusta a 2 decimales
  return area2; // <-- Aquí regresa el área ya calculada.
}

radio = prompt("Dame el valor del radio del círculo:", "Escribe un número entero");
var areaCirculo = calcularAreaCirculo(radio); // <-- areaCirculo recibe el valor calculado
document.write("El área del círculo es: " + areaCirculo);

</script>
</font>
</body>
</html>
Ejercicio 02 • Condicionales y Parámetros

Funciones definidas por el usuario

Este programa define calcularIMC(peso, altura) con dos parámetros, redondea el resultado con Math.round() y evalúa el rango mediante estructuras if / else if.

Simulador Interactivo

Salida del programa:

<!DOCTYPE html>
<html>
<meta charset="utf-8">
<title>Indice de Masa Corporal</title>
<body>
<font face="Arial">
<h2>Funciones definidas por el usuarios</h2>
<script type="text/javascript">
//Indice de masa corporal (IMC) = peso / altura (al cuadrado)
//funcion para calcular el IMC
function calcularIMC(peso, altura) {
    return peso / Math.pow(altura, 2);
}

peso = prompt("Cuanto pesas: ", "en kg"); //en kg
altura = prompt("Cuanto mides: ", "en metros"); //en metros

//Llama a la función IMC con sus dos parámetros
var IMC = Math.round(calcularIMC(peso, altura));

//Ahora evalua cual es el IMC que tienes
if (IMC >= 18.5 && IMC < 24.9) {
    document.write("El IMC es " + IMC + " Tienes un peso normal");
} else if (IMC >= 25 && IMC < 29.99) {
    document.write("El IMC es " + IMC + " Tienes sobrepeso");
} else if (IMC >= 30 && IMC < 34.99) {
    document.write("El IMC es " + IMC + " Tienes obesidad moderada");
} else if (IMC >= 35 && IMC < 39.9) {
    document.write("El IMC es " + IMC + " Tienes obesidad severa");
}
else {
    document.write("No aplica con ese peso o estatura");
}
</script>
</font>
</body>
</html>
